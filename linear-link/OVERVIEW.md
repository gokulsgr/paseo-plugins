Adds a Linear button to the header of every workspace that belongs to an AMP issue. The button shows the issue id, such as AMP-1296, and opens the issue in a browser tab inside that workspace (Paseo desktop), with the system browser as a fallback.

The issue id comes from the workspace title, then its name, then its git branch. The link points at the everquint Linear workspace. Nothing is sent to Linear and no API key is needed.
